1. Installation

  • Setup package (recommended for new installations): run NSF-Shield-x.y.z-Setup.exe. It installs to C:\Program Files\NSF Shield (a folder only administrators can change) and adds Start menu entries. The background service and start with Windows are only available in this protected installation.
  • Portable ZIP: extract the whole ZIP (right-click → Extract All; do not run it from inside the ZIP, see NSF-103) and run NSFShield.exe. Protection runs in app mode while the app stays open (also in the tray).
Administrator rights and "portable" are separate things. The program always asks for administrator rights (its manifest says requireAdministrator), installed or portable, because the WinDivert driver and the Windows DNS/proxy settings need them. "Installed" vs "portable" is only about the folder: the service and the startup task run files without asking, so they are allowed only from the protected Program Files folder (see NSF-705).
Updates. An installed copy updates itself only with a verified Setup.exe of the new version; a portable copy updates itself in place with the new ZIP and can move to the installed version with Settings → Switch to the setup package (settings are kept). Every download is checked against its SHA-256 before anything is replaced.
Antivirus warnings: the WinDivert driver used by GoodbyeDPI and Zapret may be shown as "HackTool" or "RiskTool". The engine files are the unmodified official releases; the app checks them with embedded SHA-256 values before every start (see NSF-105). If a file is blocked, report it to the antivirus vendor as a false positive first; use an exception only as a last resort (see NSF-204).

2. First use

  1. Press Start Protection. A green shield means protection runs.
  2. Press Test Discord. "Reachable" and "DNS answer: correct" should appear.
  3. If Discord was open before protection started, press Restart Discord so it connects again.
  4. If it still does not open, press Find and Connect (Simple level). The app tries the recommended methods of every available engine, stops at the first one that fully works in two rounds and switches to it.

3. Interface levels

Choose the level in Settings or on the Appearance page; both switches behave the same and never start, stop or select anything.

  • Simple (default): Start/stop protection, Find and Connect, a plain profile list with the recommended profiles of all engines (a selected or running expert profile is shown once but is not added to the scan), Troubleshooting, Appearance, Settings.
  • Standard: engine tabs, "Show expert profiles", site list templates, DNS/DoH, the network pages, the scan scope and mode, and optional candidate selection.
  • Advanced: expert profiles with technical tags, the editors of the three engines with a validated command preview, the candidate matrix, scan targets and the per-layer results, and the log.

Copy command copies the full local command only when you press it, and only for a valid profile; the preview and the log show short names, never your user folder.

5. Methods (profiles)

There are built-in methods. Recommended profiles come first in a fixed order; the others are expert profiles. Tags such as "Try on Turk Telekom" or "Try on mobile networks" are only suggestions of what to try first: they promise no success, speed, Discord voice or anti-cheat safety. The command column shows the validated command with short names (it is not a command to run).

6. Site lists (Include / Exclude)

  • Include (targeted mode): the bypass is applied only to the listed sites. All three engines support it (GoodbyeDPI --blacklist, Zapret --hostlist, ByeDPI --hosts). Every Zapret rule and every ByeDPI group gets the list; a Zapret rule that cannot know a site name (for example Discord voice) is left out in targeted mode instead of working for all traffic, and protection does not start if no rule would be left.
  • Exclude: these sites are never touched. Zapret and ByeDPI support it; GoodbyeDPI 0.2.3rc3 has no exclude list, so with GoodbyeDPI the exclude list is ignored and a warning is shown.
  • Entries are host names only (ASCII or punycode, at most 5000 per list): no addresses, ports, paths or wildcards. The lists are written to data\lists\include.txt and exclude.txt and kept write-locked while an engine reads them.

7. The smart scanner

Scopes: Recommended, Active engine, All engines, Driverless only. Modes:

  • Stop at first match: candidates run in a stable order (recommended first). It stops only at a full success and, if you asked for it, applies that profile.
  • Compare all: every candidate is tried once and ranked; nothing is applied automatically. The original state comes back first; then you can press Apply.

Each candidate runs isolated: its own process, port and temporary list files, its files locked after the SHA-256 check. Your settings and site lists are never changed by a candidate. Another program's DPI tool, driver or service is never closed; WinDivert candidates are then skipped with the reason. Cancel, errors and results that are not applied all go through one restore path; protection that was off stays off.

What the results mean

  • Score: the share of the required targets that passed in both rounds. Latency only counts successful HTTPS measurements; "—" means nothing was measured (never "0 ms").
  • HTTPS targets: every connection goes to a checked public address with a full certificate check for the original name. "The server answered" is not "the target works": 407, 451, 5xx and a redirect to another site are not a success. A redirect counts only when its Location, read against the real request, stays on an allowed HTTPS address.
  • Gateway connection (gateway.discord.gg): a short WebSocket opening to Discord's Gateway. Only "101 Switching Protocols" with valid Upgrade/Connection headers and the right Sec-WebSocket-Accept for that request is a success; no token or login is ever sent and the connection is closed right away. It says nothing about a Discord session, voice or games.
  • UDP/STUN: an optional STUN Binding (RFC 8489) to stun.cloudflare.com:3478. It never changes the score; for ByeDPI it is "N/A" (TCP proxy only). A STUN answer does not prove that QUIC, WebRTC or Discord voice works.
  • DNS: the system DNS answer is compared with DNS over HTTPS (JSON, dns.google with cloudflare-dns.com as backup). Different public CDN addresses are normal; NXDOMAIN, an empty or private answer from the system side points at interference.

8. DNS and encrypted DNS

  • DNS redirection (GoodbyeDPI profiles): DNS queries go to a secure server on a non-standard port (Yandex 1253, AdGuard 5353, Quad9 9953, OpenDNS 5353).
  • DNS page (Standard/Advanced): sets the Windows DNS server (Cloudflare, Google, Quad9, AdGuard, OpenDNS) and, on Windows 11, encrypted DNS (DoH). The previous settings are saved and can be restored.
  • The DNS chip on the home page shows the setting of the adapter that carries the internet route. "DoH" appears only when encrypted DNS is really registered for that server; the tooltip says "not supported", "registered", "not registered" or "unknown". "Mixed" means several adapters with different settings and no readable route. Automatic (DHCP) DNS is a valid choice and is not marked as a problem.

9. Find Problems and the conflict diagnosis

Troubleshooting → Start the full check checks the installation, the engine files, BFE, conflicts, VPN/proxy, antivirus, internet, clock, hosts file, DNS, protection and the Discord servers. The conflict part is read only and is the same result the home page uses:

  • DPI processes are told apart as this app's engine, a candidate of the running scan, another copy or program, or "owner unknown". A name or a folder is never proof: the exact file and the process id the app started are. During a scan the check waits until the scan has finished.
  • WinDivert driver entries: every entry found is listed with its type, state and file (this installation or another folder). "Access denied", "not found" and "stopped" are different results.
  • Anti-cheat: Riot Vanguard (vgk), FACEIT, EasyAntiCheat / EasyAntiCheat_EOS and BattlEye (BEDaisy). Only an entry that Windows reports as a kernel driver and running counts as an active driver; a user-mode service only says the product is installed. If an entry cannot be read, it is shown as "could not be checked", never as "not found". When an active anti-cheat driver and a WinDivert engine run together, an information card explains the driverless ByeDPI engine (or why it is not offered on this computer). The card opens the profile page at most; nothing is selected, started or closed. No anti-cheat compatibility or ban safety is promised.
  • VPN / WARP: an "Up" virtual adapter, a running product service (e.g. Cloudflare WARP) and the internet route actually going through the VPN are three separate findings.

10. Network changes

When the network changes (Wi-Fi, Ethernet, hotspot, connection lost), the app waits until things have been quiet for 2.5 seconds, reads the new state in the background and updates the DNS chip and the adapter summary; if notifications are on, a short note appears. The first picture after start is silent and the same state is never reported twice. During a scan one refresh is kept for afterwards. A network change never flushes DNS, tests the internet, restarts an engine, starts a scan or writes DNS/proxy settings. The connection watchdog (periodic test, if you turned it on) and the scans and repairs you start yourself work as before.

11. Sharing profiles (NSF1)

Profiles → Share → "Copy the profile code" gives a code that starts with NSF1:. Your friend copies it (also inside a share message) and chooses Profiles → Share → "Add profile from code".

  • A code contains only the method: the engine, the name, the description and that engine's method fields. Never your settings, selected profile, lists or their content, paths, ports, proxy passwords or the real command line.
  • Before anything is shown, the code is size-checked (pasted text up to 128 Ki characters, packed and unpacked data up to 64 KiB each), parsed without DTDs and checked against the engine's allow list.
  • Importing only adds a new custom profile after you confirm; "No" changes nothing. It never starts protection, selects the profile or writes files.

12. Tray icon

Closing or minimizing hides the app to the tray. The icon color shows the state:

on   off   starting   error

The tray menu offers start/stop, the recommended profiles (and the selected one), Test Discord, Find best method and Restart Discord. Ctrl+Alt+K toggles protection if enabled in Settings.

13. Proxy

If no method works (Site Analysis says "IP block"), traffic can go through a proxy you provide (the app provides none). The Proxy page (Standard/Advanced) tests a proxy, opens Discord or chosen programs with it, or sets it as the Windows proxy (the old setting is saved). Proxy passwords are stored encrypted by Windows. Discord voice (UDP) does not go through a proxy.

14. Troubleshooting

  • Shield red, "driver blocked": the antivirus blocks WinDivert → NSF-204; or use the driverless ByeDPI engine.
  • Shield green but Discord stays at "Connecting…": restart Discord → NSF-901.
  • "DNS answer: WRONG": the profile does not redirect DNS → NSF-403.
  • Nothing works: run Site Analysis; an "IP block" needs a VPN or proxy → NSF-503.

The support package (Troubleshooting) saves logs, history and a settings summary (switches and counts only: no proxy addresses, names or passwords, no program paths, no site lists) to one ZIP, with IP addresses, user names and e-mail addresses hidden. In every text file your saved proxies (address, host name, name, user name) appear as "Proxy #1", "Proxy #2"… and per-program rules as "App #1"….

16. Backup scripts

The .cmd files in the scripts folder run GoodbyeDPI directly, without the app (one per built-in GoodbyeDPI method). Zapret and ByeDPI are started by the app only. Quit NSF Shield first and run one script at a time; stop.cmd closes GoodbyeDPI, reset.cmd removes the services and the driver entry.

17. Clean uninstall

Everything NSF Shield changed in Windows (service, startup task, WinDivert driver entries of this folder, Windows proxy, DNS servers and encrypted DNS entries) is put back as it was before:

  • Installed: Settings → Apps → NSF Shield → Uninstall (you are asked whether to delete the settings too).
  • Portable: Settings → Clean uninstall in the app, then delete the folder.
  • Command line: NSFShield.exe --uninstall (quiet: --uninstall --quiet).

6. Site listeleri (Dahil / Hariç)

  • Dahil (hedefli mod): aşma yalnızca listedeki sitelere uygulanır. Üç motor da destekler (GoodbyeDPI --blacklist, Zapret --hostlist, ByeDPI --hosts). Her Zapret kuralı ve her ByeDPI grubu listeyi alır; site adını bilemeyen bir Zapret kuralı (örneğin Discord sesi) hedefli modda tüm trafiğe uygulanmak yerine dışarıda bırakılır ve hiçbir kural kalmayacaksa koruma başlamaz.
  • Hariç: bu sitelere hiç dokunulmaz. Zapret ve ByeDPI destekler; GoodbyeDPI 0.2.3rc3'te hariç listesi yoktur, bu yüzden GoodbyeDPI ile hariç listesi yok sayılır ve uyarı gösterilir.
  • Girdiler yalnızca alan adıdır (ASCII ya da punycode, liste başına en fazla 5000): adres, port, yol ya da joker karakter olmaz. Listeler data\lists\include.txt ve exclude.txt dosyalarına yazılır ve bir motor okurken yazmaya kilitli tutulur.

7. Akıllı tarayıcı

Kapsamlar: Önerilenler, Aktif motor, Tüm motorlar, Yalnızca sürücüsüz. Modlar:

  • İlk çalışanda dur: adaylar sabit sırayla (önerilenler önce) denenir. Yalnızca tam başarıda durur ve isterseniz o profili uygular.
  • Tümünü karşılaştır: her aday bir kez denenir ve sıralanır; hiçbir şey kendiliğinden uygulanmaz. Önce önceki durum geri gelir; sonra Uygula'ya basabilirsiniz.

Her aday yalıtılmış çalışır: kendi süreci, portu ve geçici liste dosyalarıyla; dosyaları SHA-256 denetiminden sonra kilitlenir. Ayarlarınız ve site listeleriniz aday tarafından asla değiştirilmez. Başka bir programın DPI aracı, sürücüsü ya da hizmeti kapatılmaz; WinDivert adayları o zaman gerekçesiyle atlanır. İptal, hata ve uygulanmayan sonuçların hepsi tek bir geri yükleme yolundan geçer; kapalı olan koruma kapalı kalır.

Sonuçların anlamı

  • Skor: zorunlu hedeflerden iki turda da geçenlerin oranı. Gecikme yalnızca başarılı HTTPS ölçümlerini sayar; "—" hiç ölçüm olmadığı anlamına gelir (asla "0 ms" değil).
  • HTTPS hedefleri: her bağlantı denetlenmiş genel bir adrese yapılır ve özgün ad için tam sertifika denetimi uygulanır. "Sunucu yanıt verdi", "hedef çalışıyor" demek değildir: 407, 451, 5xx ve başka siteye yönlendirme başarı sayılmaz. Bir yönlendirme yalnızca Location başlığı, gerçek isteğe göre okunduğunda izin verilen bir HTTPS adresinde kalıyorsa sayılır.
  • Gateway bağlantısı (gateway.discord.gg): Discord Gateway'e kısa bir WebSocket açılışı. Yalnızca geçerli Upgrade/Connection başlıkları ve o isteğe ait doğru Sec-WebSocket-Accept ile gelen "101 Switching Protocols" başarıdır; hiçbir token ya da oturum bilgisi gönderilmez ve bağlantı hemen kapatılır. Discord oturumu, ses ya da oyun hakkında bilgi vermez.
  • UDP/STUN: stun.cloudflare.com:3478 adresine isteğe bağlı STUN Binding (RFC 8489). Skoru asla değiştirmez; ByeDPI için "N/A"dır (yalnızca TCP proxy). STUN yanıtı QUIC, WebRTC ya da Discord sesinin çalıştığını kanıtlamaz.
  • DNS: sistem DNS yanıtı DNS over HTTPS (JSON; dns.google, yedek cloudflare-dns.com) ile karşılaştırılır. Farklı genel CDN adresleri normaldir; sistem tarafında NXDOMAIN, boş ya da özel adresli yanıt müdahaleye işaret eder.

8. DNS ve şifreli DNS

  • DNS yönlendirme (GoodbyeDPI profilleri): DNS sorguları standart dışı porttaki güvenli bir sunucuya gider (Yandex 1253, AdGuard 5353, Quad9 9953, OpenDNS 5353).
  • DNS sayfası (Orta/Detaylı): Windows DNS sunucusunu (Cloudflare, Google, Quad9, AdGuard, OpenDNS) ve Windows 11'de şifreli DNS'i (DoH) ayarlar. Önceki ayarlar kaydedilir ve geri alınabilir.
  • Ana ekrandaki DNS çipi, internet rotasını taşıyan bağdaştırıcının ayarını gösterir. "DoH" yalnızca o sunucu için şifreli DNS gerçekten kayıtlıysa görünür; ipucu "desteklenmiyor", "kayıtlı", "kayıtlı değil" ya da "bilinmiyor" der. "Karışık", farklı ayarlı birden çok bağdaştırıcı olduğu ve rotanın okunamadığı anlamına gelir. Otomatik (DHCP) DNS geçerli bir seçimdir ve sorun olarak işaretlenmez.

9. Sorun Bul ve çakışma teşhisi

Sorun Giderme → Tam kontrolü başlat; kurulumu, motor dosyalarını, BFE'yi, çakışmaları, VPN/proxy'yi, antivirüsü, interneti, saati, hosts dosyasını, DNS'i, korumayı ve Discord sunucularını denetler. Çakışma bölümü salt okunurdur ve ana ekranın kullandığı sonucun aynısıdır:

  • DPI süreçleri şöyle ayrılır: bu uygulamanın motoru, süren taramanın adayı, başka bir kopya ya da program, veya "sahibi belirsiz". Ad ya da klasör asla kanıt değildir; kanıt, tam dosya yolu ve uygulamanın başlattığı süreç kimliğidir. Tarama sırasında denetim, tarama bitene kadar bekler.
  • WinDivert sürücü kayıtları: bulunan her kayıt türü, durumu ve dosyasıyla (bu kurulum ya da başka bir klasör) listelenir. "Erişim reddedildi", "bulunamadı" ve "durdurulmuş" farklı sonuçlardır.
  • Hile önleyiciler: Riot Vanguard (vgk), FACEIT, EasyAntiCheat / EasyAntiCheat_EOS ve BattlEye (BEDaisy). Yalnızca Windows'un çekirdek sürücüsü ve çalışıyor olarak bildirdiği kayıt etkin sürücü sayılır; kullanıcı modu hizmeti yalnızca ürünün kurulu olduğunu söyler. Okunamayan kayıt "denetlenemedi" olarak gösterilir, asla "bulunamadı" denmez. Etkin bir hile önleyici sürücüsü ile WinDivert motoru birlikte çalışıyorsa bir bilgi kartı sürücüsüz ByeDPI motorunu (ya da bu bilgisayarda neden önerilmediğini) açıklar. Kart en fazla profil sayfasını açar; hiçbir şey seçilmez, başlatılmaz ya da kapatılmaz. Hile önleyici uyumluluğu ya da yasaklanmama garantisi verilmez.
  • VPN / WARP: "Açık" durumdaki sanal bağdaştırıcı, çalışan ürün hizmeti (ör. Cloudflare WARP) ve internet rotasının gerçekten VPN'den geçmesi üç ayrı bulgudur.

10. Ağ değişimi

Ağ değiştiğinde (Wi-Fi, Ethernet, hotspot, bağlantı kopması) uygulama ortalık 2,5 saniye sakinleşene kadar bekler, yeni durumu arka planda okur, DNS çipini ve bağdaştırıcı özetini günceller; bildirimler açıksa kısa bir not gösterir. Açılıştaki ilk okuma sessizdir ve aynı durum iki kez bildirilmez. Tarama sırasında tek bir yenileme sonraya bırakılır. Ağ değişimi asla DNS temizlemez, internet testi yapmaz, motoru yeniden başlatmaz, tarama başlatmaz ya da DNS/proxy ayarı yazmaz. Bağlantı bekçisi (açtıysanız düzenli test) ve sizin başlattığınız tarama ve onarımlar eskisi gibi çalışır.

11. Profil paylaşımı (NSF1)

Profiller → Paylaş → "Profil kodunu kopyala", NSF1: ile başlayan bir kod verir. Arkadaşınız kodu (bir paylaşım mesajının içinde de olsa) kopyalayıp Profiller → Paylaş → "Koddan profil ekle"yi seçer.

  • Kod yalnızca yöntemi içerir: motor, ad, açıklama ve o motorun yöntem alanları. Ayarlarınız, seçili profiliniz, listeleriniz ya da içerikleri, yollar, portlar, proxy şifreleri ya da gerçek komut satırı asla girmez.
  • Bir şey gösterilmeden önce kodun boyutu denetlenir (yapıştırılan metin en fazla 128 Ki karakter, paketli ve açılmış veri ayrı ayrı en fazla 64 KiB), DTD olmadan ayrıştırılır ve motorun izin listesiyle denetlenir.
  • İçe aktarma yalnızca siz onayladıktan sonra yeni bir özel profil ekler; "Hayır" hiçbir şeyi değiştirmez. Korumayı başlatmaz, profili seçmez ya da dosya yazmaz.

12. Tepsi simgesi

Pencereyi kapatınca ya da küçültünce uygulama tepsiye iner. Simgenin rengi durumu gösterir:

açık   kapalı   başlatılıyor   hata

Tepsi menüsünde başlat/durdur, önerilen profiller (ve seçili olan), Discord'u test et, En iyi yöntemi bul ve Discord'u yeniden başlat vardır. Ayarlar'dan açılırsa Ctrl+Alt+K korumayı açıp kapatır.

13. Proxy

Hiçbir yöntem işe yaramıyorsa (Site Analizi "IP engeli" diyorsa) trafik sizin sağladığınız bir proxy'den geçirilebilir (uygulama proxy sağlamaz). Proxy sayfası (Orta/Detaylı) bir proxy'yi test eder, Discord'u ya da seçtiğiniz programları onunla açar veya Windows proxy'si yapar (eski ayar kaydedilir). Proxy şifreleri Windows tarafından şifrelenerek saklanır. Discord sesi (UDP) proxy'den geçmez.

14. Sorun giderme

  • Simge kırmızı, "sürücü engellendi": antivirüs WinDivert'i engelliyor → NSF-204; ya da sürücüsüz ByeDPI motorunu kullanın.
  • Simge yeşil ama Discord "Bağlanılıyor…"da kalıyor: Discord'u yeniden başlatın → NSF-901.
  • "DNS yanıtı: YANLIŞ": profil DNS'i yönlendirmiyor → NSF-403.
  • Hiçbir şey çalışmıyor: Site Analizi'ni çalıştırın; "IP engeli" çıkarsa VPN ya da proxy gerekir → NSF-503.

Destek paketi (Sorun Giderme) günlükleri, geçmişi ve bir ayar özetini (yalnızca anahtarlar ve sayılar: proxy adresi, adı ya da parolası, program yolu ve site listesi yok) IP adresleri, kullanıcı adları ve e-posta adresleri gizlenmiş olarak tek bir ZIP'e kaydeder. Her metin dosyasında kayıtlı proxy'leriniz (adres, ana makine adı, ad, kullanıcı adı) "Proxy #1", "Proxy #2"… ve program kuralları "App #1"… olarak görünür.

16. Yedek betikler

scripts klasöründeki .cmd dosyaları GoodbyeDPI'ı uygulama olmadan doğrudan çalıştırır (her hazır GoodbyeDPI yöntemi için bir dosya). Zapret ve ByeDPI yalnızca uygulama tarafından başlatılır. Önce NSF Shield'den çıkın ve aynı anda tek betik çalıştırın; stop.cmd GoodbyeDPI'ı kapatır, reset.cmd hizmetleri ve sürücü kaydını kaldırır.

17. Temiz kaldırma

NSF Shield'in Windows'ta değiştirdiği her şey (hizmet, açılış görevi, bu klasöre ait WinDivert sürücü kayıtları, Windows proxy'si, DNS sunucuları ve şifreli DNS kayıtları) önceki hâline döndürülür:

  • Kurulumlu: Ayarlar → Uygulamalar → NSF Shield → Kaldır (ayarların da silinip silinmeyeceği sorulur).
  • Taşınabilir: uygulamada Ayarlar → Temiz kaldır, ardından klasörü silin.
  • Komut satırı: NSFShield.exe --uninstall (sessiz: --uninstall --quiet).
